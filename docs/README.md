# Documentación del Portfolio Stock Tracker

- `CLINE_OPENAI_COMPATIBLE.md`: configuración de Cline con Freellmpool.
- `CLINE_FREE_LLM_APIS.md`: cómo probar en Cline/Roo un proveedor del catálogo `awesome-free-llm-apis`.
- `CLINE_OPENAI_COMPATIBLE_SETUP.md`: guía de instalación del gateway.
- `COMPATIBILITY_FIXES.md`: compatibilidad de versiones y límites conocidos.
- `IMPLEMENTATION_REPORT.md`: estado de los tres pilares funcionales.
- `MARKET_DATA_PROVIDERS.md`: fuentes de cotización, configuración de Finnhub y caché del catálogo.
- `../Abrir Portfolio Stock Tracker.bat`: inicia el dashboard local en Chrome/Edge y detiene los servicios al cerrar su ventana o pulsar Ctrl+C.

El estado vigente y las tareas pendientes se mantienen en `MEMORY.md` y
`PROJECT_MEMORY.md`, en la raíz del repositorio.
