# Estructura Frontend Android (Jetpack Compose)

Este directorio contiene las piezas clave de arquitectura en Kotlin para tu app Android de Portfolio Financiero.

## 📦 Archivos incluidos:
1. **`StockModel.kt`**: Modelo de datos (`Stock`) y respuesta del portfolio.
2. **`ApiService.kt`**: Cliente Retrofit para conectar con tu backend en FastAPI (`http://10.0.2.2:8000`).
3. **`DashboardScreen.kt`**: Pantalla principal en Jetpack Compose que muestra el listado de acciones en tiempo real, precios, variaciones y botón de análisis con Gemini.
